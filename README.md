# MarketMind – Customer Segmentation

A Data Science and Machine Learning project that groups customers based on their annual income and spending behavior using K-Means Clustering.

## Features
- Customer data analysis
- K-Means clustering
- Elbow Method
- Customer segmentation visualization
- Interactive Plotly dashboard
- Business recommendations

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Plotly
- Google Colab

## Dataset
Mall Customers dataset containing customer age, gender, annual income and spending score.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Run all cells in order.
4. Explore the customer segments and visualizations.
